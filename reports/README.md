# Reports archive

Durable output from `/analyst-brief` and any other saved research lands here, named `YYYY-MM-DD-<slug>.md`. This directory is the audit trail referenced in `analyst/GUARDRAILS.md` §6 — don't overwrite a prior day's file; each date gets its own.

`2026-09-04-global-markets-wrap.md` is the seed report this whole analyst function was generalized from — worth reading once as the reference for tone, structure, and depth before writing another one by hand.
